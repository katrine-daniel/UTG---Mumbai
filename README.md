# Delhi to Mumbai — Ultimate Travel Guide

A long-form, SEO-optimised travel guide page covering the Delhi to Mumbai journey: distance, routes, travel options, attractions and tips.

**Live demo:** https://katrine-daniel.github.io/UTG---Mumbai/

## Features

- Distance and travel-mode comparison (flight, train, road)
- Route highlights and attractions with images
- Responsive layout with Tailwind CSS

## Tech stack

HTML5, Tailwind CSS (CDN), JavaScript

## Run locally

No build step. Clone the repo and open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
